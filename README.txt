EDUJOY — промосайт для первых учителей-тестировщиков

Файлы:
- index.html — главная рекламная страница
- demo.html — демоверсия образовательной платформы EDUJOY

Проверка локально:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Кнопки «Открыть EDUJOY» ведут на demo.html.

Публикация:
Загрузите оба файла в один репозиторий GitHub и включите GitHub Pages для публикации. Не удаляйте demo.html, иначе ссылки на демо перестанут работать.

Примечание: страница не подключена к серверу и не собирает отзывы автоматически. Кнопка отзыва использует почтовую ссылку mailto.
